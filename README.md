## ⚡ What Is This?
Most AI coding agents generate generic, high-glare white/blue dashboards unless given strict visual constraints. 

**Nocturne Glass (`DESIGN.md`)** is a single-file architectural and visual blueprint. Drop `DESIGN.md` into **Google AI Studio, Cursor, Claude Code, Windsurf, Bolt, or v0** and tell the AI to build *any* dashboard—it will automatically construct a responsive, smoked-obsidian bento interface with `1px` specular highlights, squircle geometry, floating navigation docks, and Shadcn UI primitives.
